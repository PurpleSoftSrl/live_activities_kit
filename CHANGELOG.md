## 0.1.0

- Initial release
- iOS 16.1+ Live Activities with ActivityKit
- Dynamic Island layouts (compact, expanded, minimal)
- Android heads-up progress notifications with chronometer
- Specular API across both platforms
- Reactive stream-based updates
- Built-in timer/countdown mode
- Action buttons with Flutter callbacks (Android)
- Push-to-start token extraction (iOS)
- Alert configuration per update
- Dismissal policies (immediate, afterDuration, default_)
- Activity content: staleDate, relevanceScore, color, SF Symbol icons
